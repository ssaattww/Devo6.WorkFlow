## タスク

- 目的: GitHub Actions の Release 構成テスト失敗を修正する。
- タスク種別: 実装

## sub-agentを使う理由

- 理由: ユーザー指示により実装作業は sub-agent が担当するため。

## 対象範囲

- 対象: CLI 起動テストの構成解決、timeout 系テストの CI 安定化、必要な進捗とレポート更新。

- 対象外: workflow の Debug 化、NuGet 公開処理の再設計、製品コードの大規模変更。
